# Mohammed Jamai — Portfolio

A concise engineering portfolio built from the existing portfolio structure, with a minimal personal presentation.

## Notes
- Landing page is a compact business-card style entry.
- Profile includes languages, capabilities, education and certifications.
- Projects are limited to three selected projects, with a dedicated Renault ZOE project page.
- Resources open into dedicated detail views.
- CV files remain in `assets/resume/`.
- Renault ZOE project material is packaged locally under `assets/projects/zoe/`.

Open `index.html` in a browser or deploy the folder to a static host.
