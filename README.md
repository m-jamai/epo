# Mohammed Jamai — R&D / Classic Portfolio

This version preserves the structure and source content of the POLISHED portfolio while refining the visual system.

## Latest refinement
- Replaced the previous logo with a compact MJ engineering monogram aligned to the technical/editorial identity.
- Landing title is a single line on desktop, with a short human quote; the R&D label was removed from the landing page.
- Increased and balanced the spacing between the profile card and Core Capabilities.
- Core Capabilities are vertically and horizontally centered inside their cells.
- Resources now contain starter examples in all three categories: Articles & Notes, Documents & Tools, Recommendations.
- Technical Skills now map the existing skill groups to a practical self-assessed mastery level.
- Typography is unified around Manrope, with IBM Plex Mono for technical metadata and Source Serif for the human quote.

The mastery levels are explicitly presented as a self-assessment, not as an externally certified ranking.
