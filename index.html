Electric powertrain

Renault ZOE electric powertrain

Wound-rotor synchronous traction drive for a B-segment EV.

Scope

Design, modelling and field-oriented control of a 240 N·m / 100 kW wound-rotor synchronous machine for a Renault ZOE-class vehicle.

The work combines analytical machine sizing, dq steady-state modelling, loss-optimal reference calculation, voltage-limit analysis and time-domain FOC simulation.

Results

  • 97.8 kg active machine mass
  • 2.46 N·m/kg torque density
  • 94.9 / 95.5 / 96.1 % loss-optimal efficiency at points A / B / C
  • ≈ 8.9 s simulated 0–100 km/h
  • 0.3 / 0.7 % FOC torque overshoot at points A / C
